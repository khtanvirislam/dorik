<h1> Dorik Website Template </h1>
A responsive and visually appealing website template powered by HTML and CSS, designed for businesses or individuals seeking a sleek and modern website solution.

<h2>Features</h2>
  <ul>
    <li>Customizable: Built with clean and modular CSS for easy customization.</li>
    <li>Google Fonts Integration: Includes the Poppins font for a polished look.</li>
    <li>Hero Section: Features a compelling call-to-action and a showcase of key benefits.</li>
    <li>Testimonials Section: Highlights client feedback with elegant design.</li>
    <li>Video Support: Embedded video player for promotional or introductory videos.</li>
  </ul>
